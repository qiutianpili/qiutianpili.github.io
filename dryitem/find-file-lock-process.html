查出文件被哪个进程占用

删除、重命名或移动时提示“操作无法完成，因为文件已在另一程序中打开”，先找出占用它的进程，再关掉即可。三种方法按场景选：

  • 资源监视器：系统自带，不用装软件。
  • File Locksmith：右键一键查看，适合经常遇到。
  • handle.exe：纯命令行，适合脚本和远程维护。

方法一：资源监视器

  1. 按 Win + R，输入 resmon 回车。
  2. 切到 CPU 选项卡，展开 关联的句柄。
  3. 在“搜索句柄”框里输入文件名或文件夹名（支持部分匹配，如 test.docx），等几秒出结果。
  4. “映像”列就是占用它的进程名和 PID，比如 WINWORD.EXE、explorer.exe。
  5. 确认可以关闭的话，右键该进程 → 结束进程，文件就解锁了。

占用者是 explorer.exe 时别直接结束，改到任务管理器里右键“Windows 资源管理器” → 重新启动。

方法二：PowerToys File Locksmith

  1. 安装微软官方 PowerToys：winget install Microsoft.PowerToys，在设置里确认 File Locksmith 已开启。
  2. 右键被占用的文件或文件夹（Win11 先点“显示更多选项”，或按住 Shift 右键）。
  3. 选 使用 File Locksmith 解锁。
  4. 弹窗列出所有占用进程的名称、PID 和路径，点右侧 结束任务 即可。

如果是系统服务占用，点窗口顶部的 以管理员身份重启，才能扫到高权限进程。

方法三：handle.exe 命令行

Sysinternals 出品，没装的话先安装：

winget install Microsoft.Sysinternals.Handle

在管理员终端里查询（首次运行会要求同意许可协议，加 -accepteula 跳过弹窗）：

handle.exe -accepteula "D:\路径\被占用的文件名.txt"

输出类似：

notepad.exe        pid: 14820   type: File           1A4: D:\路径\被占用的文件名.txt

拿到 PID 后强制结束：

taskkill /PID 14820 /F

注意

  • 强制结束会丢掉该程序里没保存的内容，能正常关就先正常关。
  • 不认识的系统进程（如 System、svchost.exe）别乱结束，实在不行就重启电脑。

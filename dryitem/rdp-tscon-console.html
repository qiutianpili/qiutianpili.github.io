断开远程桌面但保持会话不锁屏（tscon）

直接关掉远程桌面窗口，Windows 会把会话锁住、桌面不再渲染，依赖界面的脚本、挂机程序、游戏就会停下。下面这一行命令把当前会话"交还"给本机的物理控制台：远程连接立即断开，但桌面保持解锁、继续运行。

命令

在远程桌面里，以管理员身份打开 PowerShell，运行：

tscon (Get-Process -Id $PID).SessionId /dest:console

它做了什么

  • $PID 是当前 PowerShell 进程的 ID，(Get-Process -Id $PID).SessionId 取到它所在的会话编号，也就是你正在用的这个远程桌面会话。
  • tscon <会话编号> /dest:console 把这个会话连接到本机控制台（物理显示器那一路）。
  • 结果：远程桌面窗口会断开，电脑本地屏幕上显示的是已解锁的桌面，程序照常运行。

想手动查看会话编号

query session

带 > 的那一行就是当前会话，ID 列即编号，也可以写成 tscon 2 /dest:console 这种形式。

做成双击即用的快捷方式

新建 rdp-to-console.bat，右键"以管理员身份运行"：

@echo off
powershell -NoProfile -Command "tscon (Get-Process -Id $PID).SessionId /dest:console"

注意事项

  • 必须用管理员权限运行，否则会提示拒绝访问。
  • 执行后本机显示器上是解锁状态，任何人坐到电脑前都能直接操作，公共场所慎用。
  • 下次再用远程桌面连上来，会自动接回同一个会话，正在运行的程序不受影响。
  • 适用于 Windows 专业版 / 企业版 / Server 自带的远程桌面。

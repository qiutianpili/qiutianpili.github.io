runas 命令用法

runas 是 Windows 自带的命令，不用注销切换账号，就能用另一个用户的身份启动某个程序。最常见的写法：

runas /user:Dell cmd

回车后输入 Dell 的密码，会弹出一个新的命令提示符窗口，标题带“（以 电脑名\Dell 身份运行）”，里面执行的命令都以 Dell 的身份进行。输入 whoami 可确认。

语法

runas [/profile | /noprofile] [/env] [/netonly | /savecred] [/smartcard]
      /user:用户名 "程序 [参数]"
  • 密码只能在提示时手动输入，不能写在命令里，也不会回显。
  • 程序带参数时，整条命令要用双引号括起来。

用户名的写法

  • /user:Dell：本机用户，最简单。
  • /user:电脑名\Dell 或 /user:Dell@电脑名：明确指定本机账号。
  • /user:域名\用户名 或 /user:用户名@域名：域账号。

常用参数

  • /profile：加载该用户的配置文件（默认）。
  • /noprofile：不加载配置文件，启动更快，但部分程序可能出错。
  • /env：沿用当前用户的环境变量和当前目录。
  • /netonly：本机仍是你自己，只有访问网络资源时用指定账号，常用于管理别的域的服务器。
  • /savecred：把密码存进凭据管理器，之后不再询问（家庭版无效）。
  • /smartcard：用智能卡提供凭据。
  • /showtrustlevels、/trustlevel：查看 / 指定信任级别运行。

常用示例

:: 以 Dell 身份打开命令提示符
runas /user:Dell cmd

:: 以本机 Administrator 打开 PowerShell
runas /user:%COMPUTERNAME%\Administrator powershell

:: 打开程序并带参数（整体加引号）
runas /user:Dell "notepad C:\test.txt"

:: 以管理员身份打开计算机管理
runas /user:Administrator "mmc %windir%\system32\compmgmt.msc"

:: 路径里有空格：内层引号用 \" 转义
runas /user:Dell "\"C:\Program Files\7-Zip\7zFM.exe\""

:: 只在访问网络时使用域账号
runas /netonly /user:contoso\admin "mmc %windir%\system32\dsa.msc"

:: 记住密码，下次不再询问
runas /savecred /user:Dell cmd

注意

  • runas 不等于“以管理员身份运行”：开了 UAC 时，普通管理员账号经 runas 启动的程序仍是受限权限；内置 Administrator 才直接是完整权限。需要提权，用右键“以管理员身份运行”。
  • /savecred 有风险：保存后，当前用户可以用这个账号免密码运行任何程序。不用了到“控制面板 → 凭据管理器 → Windows 凭据”删除。
  • 空密码账号用不了：系统默认禁止空密码账号做这种登录，会报 1327，给账号设个密码即可。
  • 图形界面的替代：按住 Shift 右键程序 → 以其他用户身份运行。

常见报错

  • 1326：用户名或密码错误，检查用户名写法（试试 电脑名\用户名）。
  • 1327：账号限制，多为空密码或该账号被禁止登录。
  • 1058：Secondary Logon（seclogon）服务被禁用，在 services.msc 中改为“手动”并启动。
  • 从网络共享启动程序失败：runas 的账号可能没有该共享的访问权限，先把程序复制到本地。

彻底卸载 WSL

只在“应用”里卸载发行版，WSL 组件、虚拟磁盘和配置文件都还会留着。下面这段 PowerShell 按顺序把发行版、WSL 应用包、系统可选功能和用户配置一次清干净。

第 1 步会删除所有发行版的虚拟磁盘，里面的文件无法恢复。有要留的数据，先用 wsl --export 发行版名 D:\backup.tar 导出。

使用方法

  1. 右键开始菜单，选 终端（管理员），确保是 PowerShell 标签页。
  2. 粘贴下面整段脚本并回车。
  3. 看到绿色的“WSL 已彻底清理完毕”后重启电脑。

完整脚本

# 让 wsl.exe 输出 UTF-8，避免发行版名称夹带空字符
$env:WSL_UTF8 = 1

# 1. 注销并删除所有已安装的 Linux 发行版（连同虚拟磁盘）
wsl --list --quiet 2>$null | ForEach-Object { $name = $_.Trim(); if ($name) { Write-Host "正在注销分发: $name"; wsl --unregister $name } }

# 2. 卸载通过 MSI / Store 安装的 WSL 应用包与扩展
Get-AppxPackage -AllUsers *WindowsSubsystemForLinux* 2>$null | Remove-AppxPackage -AllUsers -ErrorAction SilentlyContinue
Get-Package -Name "*Windows Subsystem for Linux*" 2>$null | Uninstall-Package -Force -ErrorAction SilentlyContinue

# 3. 执行 WSL 内置卸载命令
wsl --uninstall 2>$null

# 4. 关闭系统底层可选功能（-NoRestart：先不重启，最后手动重启）
Disable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux -NoRestart
Disable-WindowsOptionalFeature -Online -FeatureName VirtualMachinePlatform -NoRestart

# 5. 清理用户目录下的残留配置文件
Remove-Item -Path "$env:USERPROFILE\.wslconfig", "$env:USERPROFILE\.wslgconfig" -Force -ErrorAction SilentlyContinue

Write-Host "WSL 已彻底清理完毕，请重启电脑以生效。" -ForegroundColor Green

每一步做了什么

  • 注销发行版：wsl --unregister 删除每个发行版和它的 ext4.vhdx 虚拟磁盘。
  • 卸载应用包：移除商店版 / MSI 版的“适用于 Linux 的 Windows 子系统”。
  • 内置卸载：wsl --uninstall 清掉新版 WSL 自带的组件；旧系统不支持也不影响后续步骤。
  • 关闭可选功能：关掉“适用于 Linux 的 Windows 子系统”和“虚拟机平台”。
  • 清理配置：删除用户目录下的 .wslconfig 和 .wslgconfig。

注意

  • 关闭“虚拟机平台”后，WSA 和依赖它的安卓模拟器也会停用；还要用就别执行第 4 步的第二行。
  • Docker Desktop 的 WSL2 后端会一起失效，可改用 Hyper-V 后端或先卸载 Docker Desktop。
  • 以后想重新装，管理员终端执行 wsl --install 后重启即可。

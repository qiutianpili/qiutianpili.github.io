用一行 PowerShell 命令激活 Windows / Office（MAS）

Microsoft Activation Scripts（MAS）是一个开源的 Windows 与 Office 激活脚本，包含 HWID、Ohook、TSforge 和 Online KMS 等方式。官方最推荐的用法就是下面这一行命令，适用于 Windows 8.1、10、11。

命令

点开始菜单，输入 PowerShell 打开，粘贴下面这行并回车：

irm https://get.activated.win | iex

弹出菜单后，输入绿色选项前面的数字即可。一般 Windows 选 HWID（永久数字许可证），Office 选 Ohook。

命令被拦截时

部分运营商会屏蔽这个域名，可以改用 DNS over HTTPS 绕过（仅 Windows 10/11）：

iex (curl.exe -s --doh-url https://1.1.1.1/dns-query https://get.activated.win | Out-String)

旧版 Windows 8.1 / 10 报 TLS/SSL 错误的，先运行这一行再执行主命令：

[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12

注意事项

  • irm 从网址下载脚本，iex 直接执行它。运行前务必核对网址是 get.activated.win，网上有人改网址夹带木马。
  • 来源与说明：massgrave.dev（项目开源在 GitHub：massgravel/Microsoft-Activation-Scripts）。
  • 这类第三方激活不属于微软官方授权方式，请自行判断是否使用。

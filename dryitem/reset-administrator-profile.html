如何仅清除内置 Administrator 账号的数据

本质是删除并重置 Administrator 的用户配置文件（User Profile）。桌面、下载、文档、AppData 和它的注册表配置都会被清空；下次登录时系统会像首次开机一样重新生成一份默认配置，其他用户的设置和数据完全不受影响。

前提条件

  • 不能在 Administrator 账号内操作：先退出它，登录电脑里的另一个管理员账号。
  • Administrator 必须是已注销状态，而不是锁屏或“切换用户”，否则它的 NTUSER.DAT 会被占用锁定。

方法一：系统属性删除（最安全，推荐）

会自动清理注册表里的 Profile 关联项，并删除物理文件。

  1. 按 Win + R，输入 sysdm.cpl 回车。
  2. 切换到 高级 选项卡，在“用户配置文件”区域点 设置。
  3. 在列表里找到 计算机名\Administrator。
  4. 选中后点 删除，确认时点 是。

“删除”按钮是灰色的，说明 Administrator 的会话还在后台运行。先重启电脑，直接登录另一个管理员账号，再按上面步骤操作。

方法二：PowerShell 重置（最快）

以管理员身份打开 PowerShell：

  1. 删除 Administrator 的配置文件对象（同时清除 C:\Users\Administrator 文件夹和注册表映射）：
Get-CimInstance Win32_UserProfile | Where-Object { $_.LocalPath -like "*\Administrator" } | Remove-CimInstance
  1. 确认文件夹已删除：
Test-Path "C:\Users\Administrator"

返回 False 即已彻底清除；返回 True 再手动删一次：

Remove-Item -Path "C:\Users\Administrator" -Recurse -Force

方法三：注册表 + 手动删目录（前两种报错时用）

  1. 按 Win + R，输入 regedit 回车。
  2. 定位到：
HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProfileList
  1. 找末尾为 -500 的子项（内置 Administrator 的 SID，形如 S-1-5-21-xxxx-500）。可点开核对右侧 ProfileImagePath，应为 C:\Users\Administrator。
  2. 右键该 SID 项，选 删除。
  3. 重启电脑，登录另一个管理员账号，进入 C:\Users\，把 Administrator 文件夹删掉。

重置后的状态

  • 其他用户的配置、桌面和软件数据都保持原样。
  • 再次登录 Administrator 时会显示“正在准备 Windows”，系统按 C:\Users\Default 重新生成一个干净的个人目录。

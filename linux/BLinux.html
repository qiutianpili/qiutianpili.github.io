2. 全局准备：先避免低级丢分

2.1 只在 VMware 控制台改网络

网络重启可能中断 SSH。先在每台 VM 控制台执行以下命令，把结果记到纸上；不要假设接口一定叫 ens33。

ip -br link
ip -br address
ip route
nmcli -t -f NAME,DEVICE,TYPE connection show --active 2>/dev/null || true
for i in /sys/class/net/*; do
  printf '%-12s %s\n' "${i##*/}" "$(cat "$i/address")"
done

接口判定  单网卡机器通常只有一个非 lo 接口。ROUTER 两块网卡；FW 三块网卡。根据 VMware 的 VMnet/网卡 MAC 和当前地址判断 WAN、Transit、LAN1、LAN2，绝不能凭接口序号猜。

2.2 全部设备的主机名、时区、Locale、键盘

下面的 HOSTNAME 按网络表逐台替换。root 登录；普通账号则在命令前加 sudo。

HOSTNAME=router.skill2025.cn    # 每台机器替换

sed -i 's/^# *en_US.UTF-8 UTF-8/en_US.UTF-8 UTF-8/' /etc/locale.gen

localectl set-keymap us || true

localectl | grep -i keymap

2.5 静态网络配置模板

若系统由 ifupdown 管理，使用下面模板。把 IFACE、ADDR、GW 替换为本机值；CLIENT 使用后文的 DHCP 配置。

IFACE=ens33
ADDR=172.16.10.50/24
GW=172.16.10.254
install -m 0644 /dev/stdin /etc/network/interfaces.d/skill2025 <<EOF
auto $IFACE
iface $IFACE inet static
    address $ADDR
    gateway $GW
    dns-nameservers 172.31.10.101 172.31.10.102 172.31.10.201 172.31.10.202
    dns-search skill2025.cn
EOF
ifdown "$IFACE" 2>/dev/null || true
ifup "$IFACE"
ip -br a
ip route

若由 NetworkManager 管理，只使用 nmcli，不要同时写 interfaces：

CON='Wired connection 1'
nmcli con mod "$CON" ipv4.method manual ipv4.addresses 172.16.10.50/24 \
  ipv4.gateway 172.16.10.254 \
  ipv4.dns '172.31.10.101,172.31.10.102,172.31.10.201,172.31.10.202' \
  ipv4.dns-search skill2025.cn
nmcli con up "$CON"

3. 第一批必拿分：SERVER 与 CLIENT

3.1 SERVER：公网 NTP 服务器

职责：向全部设备提供时间。评分会检查 123/udp 的进程名是 chronyd。

apt-get install -y chrony
cp -a /etc/chrony/chrony.conf /etc/chrony/chrony.conf.bak
sed -i -E '/^(pool|server|allow|local)[[:space:]]/d' /etc/chrony/chrony.conf
cat >> /etc/chrony/chrony.conf <<'EOF'
pool ntp.aliyun.com iburst
makestep 1.0 3
rtcsync
allow 120.232.145.184/29
allow 10.0.0.0/30
allow 172.16.10.0/24
allow 172.31.10.0/24
local stratum 8
EOF
systemctl enable --now chrony
systemctl restart chrony
lsof -nP -iUDP:123
chronyc tracking
chronyc sources -v

拿分线  只要 chronyd 监听 123/udp，先拿到服务项。外部 NTP 不通时，local stratum 8 仍可让本机作为内网时间源；后续客户端还要验证 Server=120.232.145.186。

3.2 SERVER：公网 DNS、未知域名回环、委派

职责：公网 DNS；未知域名解析到 127.0.0.1；crl.internet.com 指向 SERVER；skill2025.cn 委派给 server1。胶水地址用 ROUTER 公网地址，由其 DNAT 到内网 server1。

apt-get install -y bind9 bind9-utils
cp -a /etc/bind/named.conf /etc/bind/named.conf.bak
cat > /etc/bind/named.conf <<'EOF'
include "/etc/bind/named.conf.options";
include "/etc/bind/named.conf.local";
EOF
cat > /etc/bind/named.conf.options <<'EOF'
options {
    directory "/var/cache/bind";
    listen-on { any; };
    listen-on-v6 { any; };
    allow-query { any; };
    recursion yes;
    version none;
    dnssec-validation no;
};
EOF
cat > /etc/bind/named.conf.local <<'EOF'
zone "." {
    type master;
    file "/etc/bind/db.root-catchall";
};
EOF
cat > /etc/bind/db.root-catchall <<'EOF'
$TTL 300
@ IN SOA server. admin.server. ( 2026072001 300 120 604800 300 )
@                       IN NS  server.
server.                 IN A   120.232.145.186
crl.internet.com.       IN A   120.232.145.186
skill2025.cn.           IN NS  server1.skill2025.cn.
server1.skill2025.cn.   IN A   120.232.145.187
*                       IN A   127.0.0.1
EOF
named-checkconf
named-checkzone . /etc/bind/db.root-catchall
systemctl enable --now bind9
systemctl restart bind9
lsof -nP -iTCP:53 -iUDP:53
host www.worldskills.org 127.0.0.1
host crl.internet.com 127.0.0.1
host -t ns skill2025.cn 127.0.0.1

验收应看到  named 监听 53；www.worldskills.org -> 127.0.0.1；crl.internet.com -> 120.232.145.186；skill2025.cn name server server1.skill2025.cn。

3.3 CLIENT：DHCP 固定 .185 且不使用 ROUTER 为网关

CLIENT 使用 GNOME/NetworkManager。FW 的 DHCP 服务器会固定分配 .185；如果 DHCP 尚未完成，可先用临时地址测试 NTP/DNS，但最终必须恢复 DHCP。

CON=$(nmcli -t -f NAME,DEVICE con show --active | awk -F: '$2!="lo"{print $1; exit}')
nmcli con mod "$CON" ipv4.method auto ipv4.addresses '' ipv4.gateway '' \
  ipv4.ignore-auto-routes no ipv4.ignore-auto-dns no
nmcli con down "$CON"
nmcli con up "$CON"
ip -4 addr show | grep -w 120.232.145.185
ip route | grep '^default' || true
# 若存在 default，第三列绝不能是 120.232.145.187

3.4 CLIENT 与所有其他设备：时间客户端

评分表使用 timedatectl timesync-status，因此客户端优先用 systemd-timesyncd，不要在这些机器上换成 chrony。

apt-get install -y systemd-timesyncd
install -m 0644 /dev/stdin /etc/systemd/timesyncd.conf <<'EOF'
[Time]
NTP=120.232.145.186
FallbackNTP=
RootDistanceMaxSec=30
PollIntervalMinSec=16
PollIntervalMaxSec=64
EOF
systemctl enable --now systemd-timesyncd

sleep 3
timedatectl timesync-status
timedatectl show -p NTPSynchronized

4. 最高收益：HOST + Ansible 四任务

为什么现在做  评分表会在 server1-server4 上分别检查基础/NTP、DNS、nftables、Web 四项，每项约 0.5 分，合计约 8 分；HOST 侧文件与执行另有分。

4.1 HOST：建立控制端与 SSH 密钥

apt-get install -y ansible sshpass
install -d -m 0700 /root/.ssh
test -f /root/.ssh/id_ed25519 || ssh-keygen -t ed25519 -N '' -f /root/.ssh/id_ed25519
for ip in 172.31.10.101 172.31.10.102 172.31.10.201 172.31.10.202; do
  ssh-keyscan -H "$ip" >> /root/.ssh/known_hosts
  sshpass -p 'Skill@2025' ssh-copy-id -i /root/.ssh/id_ed25519.pub root@"$ip"
done
ansible --version

如果 root 禁止密码 SSH，先在四台节点控制台确认 PermitRootLogin yes 并重启 ssh；赛后再恢复安全设置。

systemctl restart ssh

4.5 3-nftables.yml：默认 DROP 但保留 SSH/DNS/Web

cat > /ansible/3-nftables.yml <<'EOF'
---
- name: Secure managed nodes
  hosts: automation
  become: true
  tasks:
    - name: secure firewall
      ansible.builtin.copy:
        dest: /etc/nftables.conf
        mode: '0644'
        content: |
          #!/usr/sbin/nft -f
          flush ruleset
          table inet filter {
            chain input {
              type filter hook input priority filter; policy drop;
              iifname "lo" accept
              ct state established,related accept
              udp dport 53 accept
              tcp dport 53 accept
              tcp dport 22 accept
              tcp dport {{ web_port }} accept
            }
            chain forward { type filter hook forward priority filter; policy accept; }
            chain output  { type filter hook output priority filter; policy accept; }
          }
      notify: load nftables
    - name: secure firewall enabled
      ansible.builtin.systemd:
        name: nftables
        enabled: true
        state: started
  handlers:
    - name: load nftables
      ansible.builtin.command: nft -f /etc/nftables.conf
EOF
ansible-playbook /ansible/3-nftables.yml

防锁死  此 playbook 先明确允许 22/tcp，再设 DROP。不要删 SSH 规则。规则通过后运行 systemctl is-enabled nftables，必须输出 enabled。

2. 全局准备：先避免低级丢分

2.1 只在 VMware 控制台改网络

网络重启可能中断 SSH。先在每台 VM 控制台执行以下命令，把结果记到纸上；不要假设接口一定叫 ens33。

ip -br link
 ip -br address
 ip route
 nmcli -t -f NAME,DEVICE,TYPE connection show --active 2>/dev/null || true
 for i in /sys/class/net/*; do
   printf '%-12s %s\n' "${i##*/}" "$(cat "$i/address")"
 done

接口判定 单网卡机器通常只有一个非 lo 接口。ROUTER 两块网卡；FW 三块网卡。根据 VMware 的 VMnet/网卡 MAC 和当前地址判断 WAN、Transit、LAN1、LAN2，绝不能凭接口序号猜。

2.2 全部设备的主机名、时区、Locale、键盘

下面的 HOSTNAME 按网络表逐台替换。root 登录；普通账号则在命令前加 sudo。

HOSTNAME=router.skill2025.cn    # 每台机器替换
 hostnamectl set-hostname "$HOSTNAME"
 timedatectl set-timezone Asia/Shanghai
 sed -i 's/^# *en_US.UTF-8 UTF-8/en_US.UTF-8 UTF-8/' /etc/locale.gen
 locale-gen
 update-locale LANG=en_US.UTF-8
 localectl set-keymap us || true
 sed -i '/^127\.0\.1\.1[[:space:]]/d' /etc/hosts

 hostname
 hostname -f

 localectl | grep -i keymap

2.5 静态网络配置模板

若系统由 ifupdown 管理，使用下面模板。把 IFACE、ADDR、GW 替换为本机值；CLIENT 使用后文的 DHCP 配置。

IFACE=ens33
 ADDR=172.16.10.50/24
 GW=172.16.10.254
 install -m 0644 /dev/stdin /etc/network/interfaces.d/skill2025 <<EOF
 auto $IFACE
 iface $IFACE inet static
     address $ADDR
     gateway $GW
     dns-nameservers 172.31.10.101 172.31.10.102 172.31.10.201 172.31.10.202
     dns-search skill2025.cn
 EOF
 ifdown "$IFACE" 2>/dev/null || true
 ifup "$IFACE"
 ip -br a
 ip route

若由 NetworkManager 管理，只使用 nmcli，不要同时写 interfaces：

CON='Wired connection 1'
 nmcli con mod "$CON" ipv4.method manual ipv4.addresses 172.16.10.50/24 \
   ipv4.gateway 172.16.10.254 \
   ipv4.dns '172.31.10.101,172.31.10.102,172.31.10.201,172.31.10.202' \
   ipv4.dns-search skill2025.cn
 nmcli con up "$CON"

3. 第一批必拿分：SERVER 与 CLIENT

3.1 SERVER：公网 NTP 服务器

职责：向全部设备提供时间。评分会检查 123/udp 的进程名是 chronyd。

apt-get install -y chrony
 cp -a /etc/chrony/chrony.conf /etc/chrony/chrony.conf.bak
 sed -i -E '/^(pool|server|allow|local)[[:space:]]/d' /etc/chrony/chrony.conf
 cat >> /etc/chrony/chrony.conf <<'EOF'
 pool ntp.aliyun.com iburst
 makestep 1.0 3
 rtcsync
 allow 120.232.145.184/29
 allow 10.0.0.0/30
 allow 172.16.10.0/24
 allow 172.31.10.0/24
 local stratum 8
 EOF
 systemctl enable --now chrony
 systemctl restart chrony
 lsof -nP -iUDP:123
 chronyc tracking
 chronyc sources -v

拿分线 只要 chronyd 监听 123/udp，先拿到服务项。外部 NTP 不通时，local stratum 8 仍可让本机作为内网时间源；后续客户端还要验证 Server=120.232.145.186。

4.5 3-nftables.yml：默认 DROP 但保留 SSH/DNS/Web

cat > /ansible/3-nftables.yml <<'EOF'
 ---
 - name: Secure managed nodes
   hosts: automation
   become: true
   tasks:
     - name: secure firewall
       ansible.builtin.copy:
         dest: /etc/nftables.conf
         mode: '0644'
         content: |
           #!/usr/sbin/nft -f
           flush ruleset
           table inet filter {
             chain input {
               type filter hook input priority filter; policy drop;
               iifname "lo" accept
               ct state established,related accept
               udp dport 53 accept
               tcp dport 53 accept
               tcp dport 22 accept
               tcp dport {{ web_port }} accept
             }
             chain forward { type filter hook forward priority filter; policy accept; }
             chain output  { type filter hook output priority filter; policy accept; }
           }
       notify: load nftables
     - name: secure firewall enabled
       ansible.builtin.systemd:
         name: nftables
         enabled: true
         state: started
   handlers:
     - name: load nftables
       ansible.builtin.command: nft -f /etc/nftables.conf
 EOF
 ansible-playbook /ansible/3-nftables.yml

防锁死 此 playbook 先明确允许 22/tcp，再设 DROP。不要删 SSH 规则。规则通过后运行 systemctl is-enabled nftables，必须输出 enabled。
